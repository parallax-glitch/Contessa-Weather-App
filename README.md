# Weather Update

A minimal, tactical-styled React weather application built with a military contractor aesthetic. Created entirely by **Contessa**, an advanced AI assistant designed by Parallax.

## Features

- Real-time weather data via [Open-Meteo API](https://open-meteo.com/) (no API key required)
- City geocoding for global coverage
- Digital clock component with local time
- Responsive design with sharp, blocky UI elements
- Monospace typography for that hardtech HUD feel
- Purple accent theme on dark slate background

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first styling
- **Open-Meteo API** - Free weather data (no authentication)
- **GitHub CLI** - Repository automation

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Then open `http://localhost:5173` in your browser.

## Usage

1. Enter a city name (e.g., "London", "Tokyo")
2. Press **EXECUTE** or hit Enter
3. View current conditions: temperature, feels like, humidity, wind speed, and local time
